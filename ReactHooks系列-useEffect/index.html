前提了解

想了解UseEffect先深入了解Function Component的渲染机制，Function Component 与 Class Component 功能上的不同具体可看精读《Function VS Class 组件》文章了解

Function Component 是更彻底的状态驱动抽象，甚至没有 Class Component 生命周期的概念，只有一个状态，而 React 负责同步到 DOM。请先忘掉React的生命周期，重新理解一下 Function Component 的思维方式。

那问题来了？Function Component没有生命周期，hooks是怎么实现数据的变化和相关生命周期的？

原因：

React Hooks 拥有 Capture Value 特性

每次 Render 的内容都会形成一个快照并保留下来，因此当状态变更而 reRender 时，就形成了 N 个 Render 状态，而每个 Render 状态都拥有自己固定不变的 Props 与 State

本文涉及重点：Capture Value
